# C Basics

Exercícios e exemplos básicos em C, focados em sintaxe,
lógica e fundamentos da linguagem.

## Conteúdo
- Hello World
- Variáveis e tipos
- Entrada e saída
- Condicionais
- Laços de repetição
- Funções

## Objetivo
Construir uma base sólida em C antes de avançar
para conceitos mais complexos.
